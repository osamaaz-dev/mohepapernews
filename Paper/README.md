# قالب ورقة القرارات

موقع ثابت (HTML + CSS + JS) يضع صفحات القرار (PDF متعدد الصفحات أو صور) داخل قالب جاهز، ثم يحمّلها كصور PNG.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` / `style.css` / `app.js` | الواجهة والمنطق |
| `templates.js` | قائمة القوالب (اسم، ملف، حجم، مكان نافذة الورقة) — **مولَّد تلقائياً** |
| `templates/*.png` | القوالب (PNG بنافذة شفافة) + `templates/thumbs/*.webp` صور مصغّرة |
| `zip.js` | إنشاء ملف ZIP عند تحميل كل الصفحات (بدون مكتبات) |
| `tools/build_templates.py` | يولّد القوالب الجديدة ويعيد تصدير قالب البيج من `ورقة قرار جديد.psd` |
| `tools/assets/` | الشعارات وأيقونات التواصل المستخرجة من ملفات PSD |

> ملفات `ورقة-قرار.png` و`ورقة-قرار-جديد.png` في المجلد الرئيسي لم تعد مستخدمة (القوالب الآن داخل `templates/`).
> ملف `ورقة-قرار-جديد.png` القديم كان بنافذة أصغر من الـ PSD الحالي؛ القالب `beige` أُعيد تصديره من الـ PSD المحدَّث.

## تشغيل الموقع

يجب فتحه عبر خادم (وليس بالنقر المزدوج على `index.html`) وإلا يمنع المتصفح التصدير:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## إضافة قالب جديد

1. صمّم PNG بأي حجم، وأترك **النافذة التي تظهر منها الورقة شفافة تماماً** (بقية القالب معتم).
   أي مساحة شفافة يجب أن تكون النافذة فقط.
2. ضعه في `templates/` وأضف سطراً في `templates.js`:

   ```js
   { id: 'mine', name: 'قالبي', file: 'templates/mine.png', thumb: 'templates/mine.png' }
   ```

   حقول `w` و`h` و`win` اختيارية — تُكتشف تلقائياً من الشفافية. `thumb` اختياري أيضاً.

أو أضف دالة جديدة في `tools/build_templates.py` (مثل `tpl_pure`) وسجّلها في `specs` ثم شغّل:

```bash
python tools/build_templates.py            # كل القوالب
python tools/build_templates.py pure gold  # قوالب محددة فقط
```

## الميزات

- **صفحات متعددة**: كل صفحة من الـ PDF تُوضع في القالب (تنقّل + شريط صفحات + ZIP).
- **محاذاة تلقائية** عند الرفع (ملاءمة الصفحة) مع خيارات: ملء الإطار / عرض كامل / قص الهوامش / توسيط.
- **تكبير سهل على الموبايل**: قرص بإصبعين + شريط تكبير دائم تحت المعاينة + أزرار ±. وعلى الحاسوب: عجلة الماوس.
- «تطبيق التعديلات على كل الصفحات» (مفعّل افتراضياً) يجعل التكبير/التحريك/التدوير يشمل كل الصفحات.
- **إرسال إلى تلغرام كملف (Document)** بجودة كاملة دون ضغط، عبر بوت (انظر أدناه).
- لصق صورة من الحافظة (Ctrl+V) وسحب/إفلات الملفات.
- اختصارات لوحة المفاتيح عند التركيز على المعاينة: الأسهم للتحريك، `+` `-` للتكبير، `0` لإعادة الملاءمة، `R` للتدوير.

## الإرسال إلى تلغرام كملف

تلغرام يضغط الصور المُرسلة كـ«صورة». الموقع يستخدم **Bot API** ليرسل التصميم كـ«مستند» فيصل كما هو:

1. في تلغرام افتح **@BotFather** وأرسل `/newbot`، ثم انسخ **الرمز (Token)**.
2. للقناة: أضف البوت **مشرفاً** بصلاحية «نشر الرسائل». للمحادثة الخاصة: افتح البوت واضغط Start.
3. في الموقع: بطاقة «التحميل» ← **إعداد** ← الصق الرمز واكتب `@اسم_القناة` (أو رقم المحادثة) ← «اختبار الاتصال» ← «حفظ».

بعدها يرسل زر «إرسال إلى تلغرام» الصفحة الحالية، أو كل الصفحات كألبوم مستندات (حتى 10 في كل ألبوم).

**الأمان:** الرمز يُدخله المستخدم ويُحفظ في **متصفحه فقط** (`localStorage`، أو `sessionStorage` إن أُلغي «تذكّر») ولا يُرسل إلا إلى `api.telegram.org`.
لا يوجد أي رمز داخل كود الموقع — لا تضعه فيه أبداً لأن أي زائر سيراه. من يملك الرمز يستطيع النشر باسم البوت، فالأفضل بوت مخصص لهذا الغرض،
وزر «مسح البيانات المحفوظة» في نافذة الإعداد يحذفه من المتصفح. قد يكون تلغرام محجوباً على بعض الشبكات فيفشل الإرسال منها.
